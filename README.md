## 规模

- **67 条功能条目**：每条含出处、设定描述、信息流分类、实现难度（L1–L5）、判定依据、注释与参见
- **67 条伦理标注**：每条另标伦理议题（N1–N10）与伦理风险等级（E0–E4），含一句话判词
- **67 条法律标注**：每条另标法律议题（J1–J8）与法律状态（V0–V4），**只依据现行法判断，超出射程的 32 条明确标注「未作判断」**
- **200 个作品总结页**：10 篇深度总结 + 190 部作品库（游戏 49 / 动画漫画 29 / 电影 58 / 剧集 19 / 小说 35）
- **22 个术语页**（Relic、Soulkiller、engram、Blackwall、Ghost、SQUID、BTL、副本问题、带宽瓶颈……）
- **28 个现实案例**：分八类现实路径（皮层内 / 血管内 / 写入刺激 / 语言解码 / 非侵入 / 监管支付 / 消费灰产 / 失败遗留），每条标证据等级 E1–E4、量化指标与**「没做到什么」**
- **20 种现有科技组合**：不发明新东西，只把现货部件拼起来能做到什么，分 A 现货可拼 / B 需器件与审批 / C 技术成立但制度未开
- **10 个伦理议题页 + 8 个法律议题页**、**8 个主题概念分组**、难度标尺、伦理标准、法律标准、现实基线、现实案例对照组、现有科技组合、完整对照表（含搜索与筛选）

## 难度标尺（全站统一）

| 等级 | 含义 |
|---|---|
| L1 | 工程可达（已有现实对应物） |
| L2 | 需要神经科学突破（缺编解码理论） |
| L3 | 需要范式级突破 |
| L4 | 物理 / 信息论层面存疑 |
| L5 | 叙事装置（不对应技术） |

标尺锚定 2026 年前后现实 BCI 进展（Neuralink N1、Synchron、2025 年全脑仿真评估等），行业数字仅作量级参照。

## 伦理标尺（与难度正交）

难度问「能不能做」，伦理问「该不该做、谁负责」。两套标尺互不推导——子弹时间是 L5 却几乎没有伦理争议，远程入侵植入体只有 L1 却已踩到人身控制。

| 等级 | 含义 | 条目数 |
|---|---|---|
| E0 | 无伦理争议（仅游戏机制或不对真实主体施加影响） | 2 |
| E1 | 有现行规范可依（器械审批 / 个保法 / 网安法） | 11 |
| E2 | 已争议、无共识（增强 vs 治疗、神经数据商用） | 15 |
| E3 | 法律框架无法覆盖（需新设神经权利） | 18 |
| E4 | 触及「人」的定义（副本是不是本人未决） | 21 |

十个议题：精神隐私、认知自由、自主与能动、身份与人格、知情同意、平等与可及、责任归属、尊严与商品化、数据主权、军事化与双用。分类骨架取自中国《脑机接口研究伦理指引》(2024-02) 与 UNESCO《神经技术伦理问题建议书》(2025-11)。

## 法律标尺（只依据现行法，不预测立法）

与难度、伦理都正交的第三个维度，只回答「按今天生效的法律，这条想象算什么」。三条硬约束：不预测立法、不评价应然、超出射程就不判断。

| 状态 | 含义 | 条目数 | 是否作判断 |
|---|---|---|---|
| V0 | 合法（无禁止性规定，不侵害他人法益） | 2 | ✅ |
| V1 | 合规可行（须许可 / 审批 / 资质 / 有效同意） | 20 | ✅ |
| V2 | 违法（有禁止性规定或对应罪名） | 13 | ✅ |
| V3 | 无规定（既未允许也未禁止，缺可适用规则） | 27 | ❌ 不判断 |
| V4 | 不进入评价（物理不可能 / 无主体 / 纯机制） | 5 | ❌ 不判断 |

八个议题：生命与身体完整、人格权与主体资格、个人信息与神经数据、医疗与器械监管、产品责任与消费者保护、网络与国家安全、刑事归责与证据、知识产权与竞争。

> **V3／V4 都不等于「合法」。** 把「不违法」读成「允许」是这套标尺最容易被误用的地方。

依据以中国《刑法》《民法典》《个人信息保护法》《数据安全法》《网络安全法》《医疗器械监督管理条例》《刑事诉讼法》为主，GDPR、EU AI Act、EU MDR、美国 CFAA／BIPA／加州 SB 1223、Oviedo 公约、ICCPR 为参照，条文以 2026-11 现行有效版本为准。**不构成法律意见。**

## 现实证据标尺（只衡量能否独立核查）

| 等级 | 含义 | 案例数 |
|---|---|---|
| E1 | 监管批准 / 上市（有准入文件或收费编码） | 9 |
| E2 | 同行评议论文 | 9 |
| E3 | 注册临床 / 官方披露（可查登记） | 8 |
| E4 | 厂商宣称 / 媒体报道（未独立核实） | 2 |

对照组纪律：**把宣称和证据分开摆放**。同一件事经常同时存在「厂商称已成功」与「公开登记查无试验」两种版本（典型 R14 Blindsight）。每个案例都单列「没做到什么」——天花板只能从反面看见。

关键结论：67 条想象里只有 22 条（33%）能找到任何现实对应物，且覆盖率从 L1 的 71% 单调降到 L5 的 9%。全球首个植入式 BCI 注册证 2026-03 才发出，适应证只有「抓握」。

## 现有科技组合档位（与难度正交）

L 问「按作品原样实现要多少次突破」，A/B/C 问「缺的是工程、审批，还是许可」。

| 档 | 含义 | 条数 |
|---|---|---|
| A | 现货可拼：部件商业可得、不需审批、今天能出原型 | 8 |
| B | 需器件与审批：部件齐全，6–36 个月 | 7 |
| C | 技术成立但制度未开：没有适应证 / 编码，或已被现行法禁止 | 5 |

关键结论：最像作品的几条（K01 神经自适应难度、K06 注意力定价、K18 外挂记忆）根本不需要碰脑；而 45 条想象连一条可拼路径都没有——不是「还没拼好」，是部件还不存在。记忆写入（K15）被明确排除在「可组合」之外，理由写在条目里。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | Wiki 主站（单文件 SPA，hash 路由，无依赖）。**这是构建产物，不要直接改** |
| `build_wiki.js` | **单一数据源**：条目数据从 `脑机接口功能想象_直观版.html` 提取；主题分组 / 术语 / 作品总结（HOT、LIB）/ 伦理（ETH）/ 法律（LAW）/ 现实案例（CASES）/ 科技组合（COMPOSE）均写在本文件里 |
| `脑机接口功能想象_直观版.html` | 67 条条目数据的来源（表格版） |
| `脑机接口功能想象对照表.md` | 完整 Markdown 对照表（人类可读版） |
| `gen_md_ethics.js` / `gen_md_law.js` / `gen_md_cases.js` | 从构建产物反向生成 Markdown 的 §6 / §7 / §8–§9，避免手抄 |
| `sync_md_work.js` | 按表头定位「出处 / 作品」列，把 67 条条目的出处值从数据源同步进 Markdown 各表（只改那一列，幂等） |

## 本地构建

```bash
node build_wiki.js          # 从表格版提取数据，校验引用，注入 Wiki
# build_wiki.js 输出的文件名是「脑机接口功能想象_Wiki.html」，更新站点时：
cp 脑机接口功能想象_Wiki.html index.html   # Windows: copy
```

需要 Node.js（任意现代版本），无其他依赖。
