# 脑机接口功能想象 · Wiki

一个把**想象**与**现实**摆在同一张表上的脑机接口 Wiki。

现实侧六层——技术条目 → 设备目录 → 临床适应证 → 监管与准入 → 可复现层 → 现实案例，
每一层都给可核查的数值与来源，买不到、做不到、还没批的地方单列出来。
每台设备的价格都标了**口径与时效风险**（`#/price`），每条技术都标了**目前最优系统与数值年表**——
价格会过期，天花板不会凭空出现。

想象侧是另一列，不是附注：游戏 / 影视 / 动画 / 小说里对 BCI 的想象（重点《赛博朋克 2077》与《黑客帝国》），
共 67 条，定位是**想象史**——人类反复想要的东西与反复害怕的东西。
它的每一条都同时挂两样东西：需要的**技术零件**（可以买、可以等）和卡住它的**量化指标**（只能靠实验）。
**想象提出要解决的问题，现实回答目前解到了哪一步。**

## 规模

- **40 条技术天花板 + 165 个年表里程碑**（v2.1 起）：每条技术单列「目前最优系统」（今天最好的是谁、到多少）与「数值年表」（这个数从哪一年变成这个数）。年表只收可核查的里程碑，用来判断瓶颈在工程还是在物理——通道数五年涨 20 倍是工程瓶颈，皮层内电极信号半衰期十年没变是生物瓶颈
- **30 台设备的价格时效核验**（v2.1 起）：每台价格挂三样——口径、核验月份、时效风险（低 / 中 / 高 / 无价）。30 台里 23 台有公开价格、9 台高风险、7 台未上市。价格是全表唯一会过期的字段，所以也单列了「引用价格的四条纪律」
- **67 条现实锚点**（v1.5 起）：每条想象都挂三样——离落地状态（已上市 / 实验室·临床 / 单点突破 / 缺多环 / 规模·物理不允许 / 非技术命题）、差在哪一环（一句话）、需要的零件与卡点指标（技术条目编号）。技术条目页反向列出「它撑起了哪些想象」，40 条技术条目零引用清零
- **18 条监管与准入路径**（v1.3 起）：中国注册 4 / 海外准入 4 / 支付与收费 4 / 临床与伦理 3 / 数据与软件合规 3。每条给谁要走、怎么走、**可核对的法定时限与费用**、真正的卡点、常见失效情形
- **14 项可复现资源**（v1.3 起）：公开数据集 6 / 代码与工具链 4 / 评测协议与陷阱 2 / 中国现状 2。含 MOABB、BCI IV 2a、PhysioNet EEGMMIDB、清华 SSVEP、DANDI/NWB、TUH EEG，以及一张八条复现清单
- **30 台设备**（v1.2 起）：科研级 7 / 非侵入·消费与康复 11 / 植入与介入 12。每台给通道数、采样率、侵入性、**认证状态**（科研用 / CE / NMPA 二类 / 三类 / FDA 510(k) / IDE 在研）、价格口径、定位与局限

## 技术条目层（v1.1 起 · 全站的地基）

这一层的用途不是科普，是给全站一个**可反驳的锚**：凡是说不出数值区间与失效条件的能力，就是还没有被工程化的能力。

| 分类 | 条数 | 覆盖什么 |
|---|---:|---|
| 信号模态 | 8 | EEG / MEG / fNIRS / ECoG / 皮层内阵列 / 血管内支架 / 深部电极 / 功能超声 |
| 实验范式 | 7 | P300 / SSVEP / 运动想象 / 皮层内运动解码 / 语音解码 / ErrP / 闭环刺激 |
| 评价指标 | 8 | 通道数 / ITR / 准确率 / 延迟 / 阻抗 / SNR 与单位产出 / 长期稳定性 / 带宽 |
| 解码算法 | 8 | CSP / 黎曼几何 / LDA / 卡尔曼滤波 / 深度学习 / 尖峰分类 / 伪迹处理 / 迁移学习 |
| 器件与工程 | 9 | Utah / Neuropixels / 柔性薄膜 / 硬膜外 / 干湿电极 / 采集 ASIC / 无线供能 / 封装 / 手术机器人 |

每条技术页与案例页双向互链：案例页列出用到的技术，技术页反过来列出对应案例；条目页则有「技术基础」，由该条目已有的案例反查得出（不手写映射，避免两处维护）。

三条读法纪律：**数值是量级锚点不是规格书**；**每条都单列失效模式**（宣传材料只写前半段）；**能说出区间才算被工程化**。

## 设备目录与适应证（v1.2 起 · 机器与人）

技术条目按「方法」组织，这一层按「产品」和「人」组织。两个入口：

| 入口 | 条数 | 每条给什么 |
|---|---:|---|
| `#/dev` 设备与产品目录 | 30 | 通道数 / 采样率 / 侵入性 / **认证状态** / 价格口径 / 定位 / 局限 |
| `#/ind` 临床适应证图谱 | 10 | 中国患者规模（附口径）/ 丧失了哪些功能 / **现有疗法的天花板** / BCI 介入点 / 疗效终点 / 难点 / 可用设备 / 监管与支付 |

三档设备的分界线不是技术先进程度，是**钱、风险与认证**：

| 档位 | 台数 | 典型通道 | 典型价格 | 认证 |
|---|---:|---|---|---|
| 科研级 | 7 | 4–5120 记录点 | 1 万美元 – 数百万美元 | 科研用，无医疗器械认证 |
| 非侵入 · 消费与康复 | 11 | 1–16 通道 | 100 美元 – 数十万元人民币 | 消费电子免注册；康复类走二类证 |
| 植入与介入 | 12 | 8–1684 通道 | 未上市（试验免费）– 47.5 万元 | 三类证 / IDE / 510(k) 限 30 天 |

读这一层的三条纪律：

1. **有证不等于好用。** 全球第一个拿到三类证的 NEO 只有 8 个导联；1024 电极的 Precision Layer 7 只被允许在术中贴 30 天。
2. **通道数不是性能。** 决定场景的是侵入性与带宽，不是电极数。
3. **价格永远不在官网。** 院端招标、科研采购、海外采购能差一倍；植入类还要叠加手术费（国内置入费 6000–6600 元/次，非侵入适配费约 960 元）。

适应证这一层只用一个标准判断：**现有疗法已经做到哪一步**。够用的地方，BCI 就没有位置；有明确天花板的地方，才值得投入。10 个适应证里只有 1 个已有上市产品。

## 难度标尺（全站统一）

| 等级 | 含义 |
|---|---|
| L1 | 工程可达（已有现实对应物） |
| L2 | 需要神经科学突破（缺编解码理论） |
| L3 | 需要范式级突破 |
| L4 | 物理 / 信息论层面存疑 |
| L5 | 叙事装置（不对应技术） |

标尺锚定 2026 年前后现实 BCI 进展（Neuralink N1、Synchron、2025 年全脑仿真评估等），行业数字仅作量级参照。

## 伦理标尺（与难度正交）

难度问「能不能做」，伦理问「该不该做、谁负责」。两套标尺互不推导——子弹时间是 L5 却几乎没有伦理争议，远程入侵植入体只有 L1 却已踩到人身控制。

| 等级 | 含义 | 条目数 |
|---|---|---|
| E0 | 无伦理争议（仅游戏机制或不对真实主体施加影响） | 2 |
| E1 | 有现行规范可依（器械审批 / 个保法 / 网安法） | 11 |
| E2 | 已争议、无共识（增强 vs 治疗、神经数据商用） | 15 |
| E3 | 法律框架无法覆盖（需新设神经权利） | 18 |
| E4 | 触及「人」的定义（副本是不是本人未决） | 21 |

十个议题：精神隐私、认知自由、自主与能动、身份与人格、知情同意、平等与可及、责任归属、尊严与商品化、数据主权、军事化与双用。分类骨架取自中国《脑机接口研究伦理指引》(2024-02) 与 UNESCO《神经技术伦理问题建议书》(2025-11)。

## 法律标尺（只依据现行法，不预测立法）

与难度、伦理都正交的第三个维度，只回答「按今天生效的法律，这条想象算什么」。三条硬约束：不预测立法、不评价应然、超出射程就不判断。

| 状态 | 含义 | 条目数 | 是否作判断 |
|---|---|---|---|
| V0 | 合法（无禁止性规定，不侵害他人法益） | 2 | ✅ |
| V1 | 合规可行（须许可 / 审批 / 资质 / 有效同意） | 20 | ✅ |
| V2 | 违法（有禁止性规定或对应罪名） | 13 | ✅ |
| V3 | 无规定（既未允许也未禁止，缺可适用规则） | 27 | ❌ 不判断 |
| V4 | 不进入评价（物理不可能 / 无主体 / 纯机制） | 5 | ❌ 不判断 |

八个议题：生命与身体完整、人格权与主体资格、个人信息与神经数据、医疗与器械监管、产品责任与消费者保护、网络与国家安全、刑事归责与证据、知识产权与竞争。

> **V3／V4 都不等于「合法」。** 把「不违法」读成「允许」是这套标尺最容易被误用的地方。

依据以中国《刑法》《民法典》《个人信息保护法》《数据安全法》《网络安全法》《医疗器械监督管理条例》《刑事诉讼法》为主，GDPR、EU AI Act、EU MDR、美国 CFAA／BIPA／加州 SB 1223、Oviedo 公约、ICCPR 为参照，条文以 2026-11 现行有效版本为准。**不构成法律意见。**

## 现实证据标尺（只衡量能否独立核查）

| 等级 | 含义 | 案例数 |
|---|---|---|
| E1 | 监管批准 / 上市（有准入文件或收费编码） | 9 |
| E2 | 同行评议论文 | 9 |
| E3 | 注册临床 / 官方披露（可查登记） | 8 |
| E4 | 厂商宣称 / 媒体报道（未独立核实） | 2 |

对照组纪律：**把宣称和证据分开摆放**。同一件事经常同时存在「厂商称已成功」与「公开登记查无试验」两种版本（典型 R14 Blindsight）。每个案例都单列「没做到什么」——天花板只能从反面看见。

关键结论：67 条想象里只有 22 条（33%）能找到任何现实对应物，且覆盖率从 L1 的 71% 单调降到 L5 的 9%。全球首个植入式 BCI 注册证 2026-03 才发出，适应证只有「抓握」。

## 现有科技组合档位（与难度正交）

L 问「按作品原样实现要多少次突破」，A/B/C 问「缺的是工程、审批，还是许可」。

| 档 | 含义 | 条数 |
|---|---|---|
| A | 现货可拼：部件商业可得、不需审批、今天能出原型 | 8 |
| B | 需器件与审批：部件齐全，6–36 个月 | 7 |
| C | 技术成立但制度未开：没有适应证 / 编码，或已被现行法禁止 | 5 |

关键结论：最像作品的几条（K01 神经自适应难度、K06 注意力定价、K18 外挂记忆）根本不需要碰脑；而 45 条想象连一条可拼路径都没有——不是「还没拼好」，是部件还不存在。记忆写入（K15）被明确排除在「可组合」之外，理由写在条目里。

## 加载与流畅度

单文件、零外部依赖：没有 CDN、没有网络字体、不用 localStorage，存到本地双击也能完整运行。

四处关键优化（2026-11-05）：

| 位置 | 原来 | 现在 |
|---|---|---|
| 顶栏 | `position:sticky` + `backdrop-filter:blur(8px)`，滚动时每帧重算高斯模糊 | 实色背景，去滤镜 |
| 目录树 | 一次性建出全部约 440 个链接节点（含折叠组） | 折叠内容放 `<template>`，展开时才搬进 DOM（首屏节点 956 → 651） |
| 正文内链 `linkify` | 每次调用对 129 个关键词重新 `esc + toLowerCase` 再扫描 | 关键词启动时预处理一次 + 结果按字符串缓存 |
| 全局搜索 | 每次按键重做 300+ 次 `join(" ").toLowerCase()` | 启动时建小写 haystack 索引；表格搜索加 90ms 防抖 |

实测（无头 Edge，同机对比）：案例页 7.30 → 2.70ms，条目页 4.40 → 1.10ms，组合页 2.70 → 1.00ms，搜索 0.25 → 0.05ms。跑 `node bench.js` 可复现。

## 版本

当前 **v1.5.0**（2026-11-05）。版本号与 Git 提交一一对应，完整内容见 [CHANGELOG.md](CHANGELOG.md)。

判断手上的副本或某个链接是不是最新，看两处：页面**页脚**常驻的 `vX.Y.Z · 构建日期`，或源码里的 `<meta name="version">`。

版本语义（本项目自定，非严格 semver）：只改内容不改结构走 `1.0.x`；新增一个维度或一类页面走 `1.x.0`；改变既有判断口径（例如难度分级定义）走 `2.0.0`。

> 注意「更新了几次」有三个不同答案：Git 提交数、线上发布次数、实质内容迭代轮数。三者不等——见 CHANGELOG 末尾「版本口径说明」。


另：线上托管要求 URL 带 `?sharecode=`，页面内的相对文件链接由 `fileHref()` 自动续接该参数，否则点开是 403。
